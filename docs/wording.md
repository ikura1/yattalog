# 画面に出す文言

知らせ・エラー・空のときの表示を、どういう言い方でそろえるか（レビュー D6・D11）。
文言を足す・直すときは、ここの型に合わせる。

## 型
| 場面 | 型 | 例 |
|---|---|---|
| うまくいった（トースト） | 「〜しました」。句点は付けない | `保存しました`、`取り消しました` |
| 記録できた（トースト） | 「やった！」から始める | `やった！ シーツ交換 を記録しました` |
| うまくいかなかった（トースト） | 「〜できませんでした」。できることがあれば、ボタンか次の一文で添える | `記録できませんでした`＋［もう一度］ |
| 入力の誤り（フォームの下） | 何を直せばよいかを言う。「〜してください」 | `メモは1000文字までです`、`アイコンには絵文字を1つ入れてください` |
| いまの状態（バナー） | 状態と、どうなれば直るか | `オフラインです。つながると記録できます` |
| 空のとき | 「まだ〜ありません」。次にできることがあれば添える | `このカテゴリにはまだイベントがありません。「＋ 追加」で作れます。` |

- **責めない**：「不正な」「無効な」「エラーが発生しました」は使わない
- **仕組みの言葉を出さない**：「サーバー」「リクエスト」「ID」などは、ふつうに使っていて出る文言には入れない
- **「前」を付ける**：経過は「3日前」「2時間前」（決定 048）
- 同じことは、どこでも同じ言い方にする（下の一覧）

## 一覧
### 記録
| いつ | 文言 | どこ |
|---|---|---|
| タップで記録できた | `やった！ ◯◯ を記録しました`＋［取り消す］［メモ］［シェア］［詳細］ | トースト |
| 連続記録が伸びた | `🔥 3日連続！` | トースト |
| シートから記録できた | `やった！ 記録しました` | トースト |
| 記録を直した／消した | `記録を更新しました`／`記録を削除しました` | トースト |
| 取り消した | `取り消しました` | トースト |
| 記録してから10分以内に、長押しシートを開いた | `10/14 9:05 に記録しました`＋［さっきの記録を取り消す］ | 長押しシート |
| 記録できなかった | `記録できませんでした`＋［もう一度］ | トースト |
| 取り消せなかった | `取り消せませんでした`＋［もう一度］ | トースト |
| 未来の日付を選んだ | `未来の日付は記録できません。今日までの日付を選んでください` | フォーム |
| まだ来ていない時刻を入れた | `まだ来ていない時刻です。時刻を直すか、空欄にしてください` | フォーム |

### シェア
| いつ | 文言 | どこ |
|---|---|---|
| 投稿文 | `🛏️ シーツ交換 やった！ 🔥 5週連続 #Yattalog https://…` | 共有シート、X |
| 見出し | `🔥 5週連続`（下に `通算 24回目`）／`24回目`／`🎉 10回目`／`はじめての記録` | シェア画像。「何日ぶり」は使わない（決定 053 の追記） |
| 共有シートに画像を渡せなかった | `この環境では、共有シートに画像を渡せませんでした。「画像を保存する」で保存して、投稿に添えてください` | シェアのシート |

### イベント・カテゴリ
| いつ | 文言 | どこ |
|---|---|---|
| 追加・保存・削除・アーカイブ・戻す | `追加しました`／`保存しました`／`削除しました`／`アーカイブしました`／`ホームに戻しました` | トースト |
| テンプレートから追加した | `3件を追加しました` | トースト |
| 並べ替えを保存できなかった | `並べ替えを保存できませんでした`（一覧は、保存されている順に戻す） | トースト |
| 名前が空・長い | `名前を入力してください`／`名前は40文字までです` | フォーム |
| アイコンが絵文字1つでない | `アイコンには絵文字を1つ入れてください` | フォーム |
| 同じ名前のカテゴリがある | `同じ名前のカテゴリがあります` | フォーム |

### ふりかえり
| いつ | 文言 | どこ |
|---|---|---|
| 1年のまとめ | `この1年で 278 回、214 日やった`（やらなかった日数は出さない） | ふりかえり |
| 選んだ日に記録がない | `この日の記録はありません` | ふりかえり |
| この1年でよくやったこと | `この1年でよくやったこと`＋`💪 筋トレ　78回`（上位3つ。「すべて」のときだけ） | ふりかえり |
| いちばんよくやった月 | `いちばんよくやったのは 2026年4月（9回）` | イベント詳細 |
| 1年前の今ごろ | `1年前の今ごろ`＋`☀️ 布団を干す　10月13日・10月17日`（なければ出さない） | ふりかえり |
| よくやる時間帯 | `よくやるのは 朝`／`どの時間帯も同じくらい`／`時刻つきの記録が増えると、よくやる時間帯がわかります` | イベント詳細 |
| よくやる日にち | `よくやるのは 上旬`／`月のうち、いつも同じくらい`／`記録が増えると、よくやる日にちがわかります` | イベント詳細 |
| はじめての記録 | `はじめての記録 2025年8月3日（1年2か月前）` | イベント詳細 |
| よくやる曜日 | `よくやるのは 土・日曜`／`どの曜日も同じくらい`／`記録が増えると、よくやる曜日がわかります` | イベント詳細 |
| メニューの入口 | `ふりかえり`＋`この1年に、いつ何をやったかを見られます` | メニュー |

### つながり・制限
| いつ | 文言 | どこ |
|---|---|---|
| オフライン | `オフラインです。つながると記録できます` | バナー、トースト |
| オフラインで開いた | `オフラインです`＋［もう一度開く］ | 専用の画面（決定 049） |
| 通信できなかった | `通信できませんでした。つながっているか確認してください` | トースト |
| サーバーがうまく返せなかった | `うまくいきませんでした。もう一度お試しください` | トースト |
| 操作が多すぎる（429） | `操作が多すぎます。少し待ってから、もう一度お試しください` | トースト、画面 |

### ログイン・アカウント
| いつ | 文言 | どこ |
|---|---|---|
| 満員で登録できない | `ただいま満員のため、新しい登録を止めています。登録済みの方は、そのままログインできます。` | ログイン画面 |
| メールアドレスが未確認 | `確認済みのメールアドレスを持つ Google アカウントでログインしてください。` | ログイン画面 |
| 利用を止められている | `このアカウントは、利用を停止しています。心当たりがない場合は、プライバシーポリシーにある問い合わせ先までご連絡ください。` | ログイン画面 |
| 退会した | `退会しました。データはすべて削除しました。ご利用ありがとうございました。` | ログイン画面 |

## ふつうは出ない文言
画面からの操作では起きないはずのもの（通信を書き換えたとき、古い画面のまま操作したときなど）。型には合わせていない。
`ID の形式が正しくありません`、`日付の形式が正しくありません`、`時刻の形式が正しくありません`、`並び順の指定が正しくありません`、`並べ替えの位置が見つかりません`、`カテゴリが見つかりません`、`知らないテンプレートです`

## まだ決めていないもの
- 写真のアップロードの失敗、保存量の上限（写真を入れるときに。決定 044）
- 読み込み中の表示（いまは、楽観的更新と、シートが開くまでの短い待ちだけ。遅いと感じたら足す）
