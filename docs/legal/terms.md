# Yattalog 利用規約

> **ドラフト**：一般的な個人向け Web サービスを想定した下書きです。【 】の部分を埋め、公開前に必要に応じて専門家の確認を受けてください。

制定日：【2026年◯月◯日】

この利用規約（以下「本規約」）は、【運営者の氏名または屋号】（以下「運営者」）が提供する「Yattalog」（以下「本サービス」）の利用条件を定めるものです。本サービスを利用するすべての方（以下「ユーザー」）に適用されます。

## 第1条（同意）
1. ユーザーは、本規約に同意したうえで本サービスを利用するものとします。
2. ユーザーが本サービスにログインした時点で、本規約に同意したものとみなします。
3. 未成年のユーザーは、親権者などの法定代理人の同意を得たうえで本サービスを利用してください。

## 第2条（アカウント）
1. 本サービスは、Google アカウントを使ってログインします。
2. ユーザーは、自分のアカウントを自分の責任で管理するものとします。第三者による不正利用が疑われる場合は、すみやかに運営者に連絡してください。
3. 1人のユーザーが複数のアカウントを作ることや、アカウントを第三者に譲渡・貸与することはできません。

## 第3条（料金）
本サービスは無料で提供します。将来、有料の機能を追加する場合は、事前に料金と内容を本サービス上で案内します。ユーザーが同意しない限り、料金が発生することはありません。

## 第4条（ユーザーのデータ）
1. ユーザーが本サービスに登録したイベント、記録、メモ、写真など（以下「ユーザーデータ」）の権利は、ユーザーに帰属します。
2. 運営者は、本サービスを提供・維持・改善するために必要な範囲でのみ、ユーザーデータを保存・処理します。ユーザーデータを広告に使ったり、販売したりすることはありません。
3. ユーザーは、本サービスの機能を使って、いつでも自分のデータを書き出すことができます。
4. ユーザーは、他人の肖像や個人情報が写った写真、第三者の権利を侵害する内容を登録しないでください。

## 第5条（禁止事項）
ユーザーは、本サービスの利用にあたり、次の行為をしてはなりません。
1. 法令または公序良俗に反する行為
2. 犯罪行為に関連する行為
3. 第三者の著作権、肖像権、プライバシーその他の権利を侵害する行為
4. 本サービスのサーバーやネットワークに過度な負荷をかける行為、または本サービスの運営を妨げる行為
5. 本サービスに不正にアクセスする行為、不正なプログラムを送る行為
6. 本サービスの仕組みを、運営者が想定しない方法で大量に自動操作する行為（運営者が提供する API や AI 連携を、定められた範囲で使う場合を除きます）
7. 他のユーザーになりすます行為
8. 本サービスを、運営者の許可なく営利目的で利用する行為
9. その他、運営者が不適切と判断する行為

## 第6条（利用の停止など）
運営者は、ユーザーが本規約に違反した場合、または違反するおそれがあると判断した場合、事前に通知することなく、そのユーザーの利用を一時的に停止したり、アカウントを削除したりすることがあります。

## 第7条（外部サービスとの連携）
1. 本サービスでは、Google アカウントによるログインや、SNS への共有、AI アシスタントとの連携（MCP）などの機能を提供します。
2. これらの外部サービスの利用には、それぞれのサービスの規約が適用されます。外部サービスの利用によって生じたことについて、運営者は責任を負いません。ただし、運営者の故意または重大な過失による場合は除きます。
3. AI アシスタントとの連携を許可した場合、そのアシスタントは、ユーザーが許可した範囲で、ユーザーデータの読み取りと記録の追加を行います。連携は設定画面からいつでも解除できます。

## 第8条（サービスの変更・中断・終了）
1. 運営者は、事前に通知することなく、本サービスの内容を変更することがあります。
2. 運営者は、システムの保守、障害、天災その他やむを得ない理由がある場合、本サービスを一時的に中断することがあります。
3. 運営者は、本サービスを終了することがあります。その場合は、終了日の30日前までに本サービス上で通知し、ユーザーがデータを書き出せる期間を設けます。

## 第9条（退会）
1. ユーザーは、設定画面から、いつでも退会できます。
2. 退会すると、ユーザーデータはすべて削除され、元に戻すことはできません。バックアップに残っている分も、30日以内に削除します。

## 第10条（保証の否認と免責）
1. 運営者は、本サービスにバグや不具合がないこと、特定の目的に適合することを保証しません。
2. 運営者は、ユーザーデータの消失・破損などによりユーザーに生じた損害について、運営者の故意または重大な過失による場合を除き、責任を負いません。
3. 運営者がユーザーに対して損害賠償責任を負う場合でも、運営者の故意または重大な過失による場合を除き、その範囲は、ユーザーに直接かつ現実に生じた通常の損害に限られます。
4. 前各項の定めは、消費者契約法その他の法令によって無効とされる範囲では適用しません。

## 第11条（本規約の変更）
1. 運営者は、民法第548条の4の規定に基づき、必要に応じて本規約を変更することがあります。
2. 本規約を変更する場合は、変更後の内容と効力が生じる日を、効力が生じる日の一定期間前までに本サービス上で通知します。
3. 効力が生じた日以降にユーザーが本サービスを利用した場合、変更後の本規約に同意したものとみなします。

## 第12条（個人情報の取り扱い）
運営者は、ユーザーの個人情報を、別に定める「プライバシーポリシー」に従って取り扱います。

## 第13条（連絡方法）
運営者からユーザーへの連絡は、本サービス上での表示、またはユーザーの Google アカウントのメールアドレスへの送信によって行います。ユーザーから運営者への連絡は、次の問い合わせ先にお願いします。
- 問い合わせ先：【メールアドレスまたは問い合わせフォームの URL】

## 第14条（準拠法・管轄裁判所）
1. 本規約は、日本法に従って解釈します。
2. 本サービスに関して紛争が生じた場合は、【運営者の住所地を管轄する地方裁判所】を第一審の専属的合意管轄裁判所とします。
