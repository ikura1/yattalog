# 062. 「この1年でよくやったこと」と「いちばんよくやった月」を出す

- 日付：2026-10-15
- 状態：決定

## 背景
統計にあったら面白い指標（決定 060 の背景）のうち、残っていた2つを入れる。どちらも、やったことだけを数える前向きなもの。

## 決定
- **この1年でよくやったこと**（ふりかえり、草の下）：草と同じ1年分（53週）で、回数の多いイベントを3つ出す（「💪 筋トレ　78回」）。「すべて」を見ているときだけ（1つに絞っているときは意味がないので出さない）。同じ回数なら、ホームの並び順
- **いちばんよくやった月**（イベント詳細、「はじめての記録」の下）：「いちばんよくやったのは 2026年4月（9回）」。同じ回数なら新しい月。2回に届かなければ出さない
- アーカイブしたイベントの記録も、ふりかえりの「すべて」と同じく数える

## 見送ったもの
- 年のまとめ：12月に出すのがちょうどよいので、11月ごろに作る
- 4位以下の一覧：ふりかえりが長くなる。3つで十分
