# 054. 押し間違いは、10分以内なら長押しシートから取り消せる

- 日付：2026-10-14
- 状態：決定（028 の取り消しに追加。#28 の一部）

## 背景
タイルは、触るだけで記録される（決定 006・028）。スクロール中に指が当たると、気づかないうちに記録が増える。
「取り消す」は、記録した直後の知らせに5秒だけ出る。消えた後に取り消すには、編集モード → タイル → 履歴 → 削除、と4手かかっていた。

## 決定
- 記録してから **10分以内**なら、長押しシートのいちばん上に、「さっきの記録を取り消す」を出す。2手（長押し → 取り消す）で済む
- 確認の画面は出さない（知らせの「取り消す」と同じ扱い）
- 「さっき」は、記録の日付ではなく、**実際に操作した時刻**で決める。過去の日付で付けた記録も、付けた直後なら取り消せる
- 対象は、そのイベントの、いちばん新しく付けた記録だけ
- 10分を過ぎた記録は、今までどおり、履歴から削除する（確認つき）

## 理由
- 押し間違いに気づくのは、たいてい直後。ただし、5秒では短い（#28）
- 10分あれば、気づいてから落ち着いて取り消せる。長すぎると、「取り消す」と「記録を消す」の区別があいまいになる
- 確認を出さないのは、直後の取り消しを軽くするため。10分を過ぎたものは、確認つきの削除に任せる

## 影響・トレードオフ
- 長押しシートを開くたびに、いちばん新しい記録を1件調べる
- 続けて2回記録した場合、取り消せるのは新しいほうから1件ずつ
- 知らせの「取り消す」が5秒で消えること自体は、変えていない（知らせは、触っている間は消えない）
