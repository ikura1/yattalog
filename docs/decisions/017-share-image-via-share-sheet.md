# 017. SNS へのシェアは「シェア画像＋共有シート」で行う

- 日付：2026-10-10
- 状態：決定

## 背景
やったことを X やインスタに投稿できるようにしたい。

## 決定
- 記録からシェア画像（1080×1350px）を作り、Web Share API でスマホの共有シートに渡す
- X には、投稿文を入れた Web Intent（投稿画面を開くリンク）も用意する
- アプリから各 SNS の API で直接投稿することはしない
- 記録ごとの公開ページ（リンクカードが出る URL）は、v1 では作らない
- メモと写真は、本人が選んだときだけ画像に載せる

## 理由
- X の投稿 API は有料で、インスタには個人アカウントに投稿する API がない。どちらも審査や OAuth 連携が必要で、運用コストに見合わない
- 共有シートなら、インスタ（フィードとストーリーズ）、X、LINE など、端末に入っているどのアプリにも渡せる
- 公開ページを作らなければ、記録の公開範囲を管理する必要がなく、プライバシーのリスクも小さい

## 影響・トレードオフ
- シェア画像はクライアント側（Canvas）で作る。サーバー側での画像生成は不要
- X の Web Intent では画像を添付できない。画像付きで投稿したいときは、共有シートから X を選んでもらう
- 共有シートでファイルを渡せない環境（一部の PC ブラウザ）では、画像の保存で代わりにする
- 公開ページを作らないので、X にリンクカードは出ない。アプリの宣伝効果を高めたくなったら、ランディングページの OGP で対応する
