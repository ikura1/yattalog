# 002. 一般公開する

- 日付：2026-10-10
- 状態：決定

## 背景
自分専用にするか、誰でも使えるサービスとして公開するかを決める必要があった。

## 決定
誰でも登録して使えるサービスとして一般公開する。

## 理由
作り手本人が使いたいと考えていることに加えて、汎用的なアプリなので他の人にも使ってもらえる見込みがある。

## 影響・トレードオフ
v1 から次の対応が必要になる（ステップ5で詳細を決める）。
- 利用規約、プライバシーポリシー、問い合わせ窓口
- 退会とデータ削除（個人情報保護の観点）
- 新規登録時のメール確認とパスワードリセットのためのメール送信
- スパム登録や大量アップロードへの対策（レート制限など）
- 運用コストと障害対応を自分で負う
