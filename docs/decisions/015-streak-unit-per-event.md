# 015. 連続記録の単位をイベントごとに選べるようにする（なし／毎日／毎週／毎月）

- 日付：2026-10-10
- 状態：決定

## 背景
014 では、連続記録を「毎日」だけで数えていた。
しかし、シーツ交換は毎週、散髪は毎月のように、イベントによって自然な頻度は違う。
毎日やらないイベントにも「🔥5週連続」「🔥4か月連続」のような気持ちよさを出したい。

## 決定
- イベントに「連続記録の単位」を持たせる。選択肢は「なし／毎日／毎週／毎月」、初期値は「毎日」
- 週は月曜始まり、月は暦月で区切る
- 連続回数は、記録がある期間の連続数で数える。今の期間がまだでも、1つ前の期間まで続いていればバッジを控えめに表示する
- 期限切れの警告・通知・「途切れました」の表示はしない

## 理由
- 頻度の違うイベントでも、同じ仕組みで「続いている」ことを可視化できる
- これは「この頻度でやるべき」という目標ではなく、**連続をどの単位で数えるか**の設定にとどめる。そのため 007（目安の間隔・期限を持たせない）は維持される

## 影響・トレードオフ
- 014 を拡張する（014 の内容は「単位＝毎日」の場合にあたる）
- イベントのデータに `streak_unit` を追加する
- 「週2回」「2週間ごと」のような、回数や間隔の指定には対応しない。要望が出たら別途検討する
- 「今週はまだ」の控えめな表示が、人によってはプレッシャーに感じられるかもしれない。PoC で様子を見る
