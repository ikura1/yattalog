# 036. カテゴリに絵文字を付けられるようにする（任意）

- 日付：2026-10-11
- 状態：決定（013 のカテゴリに追加）

## 背景
カテゴリのタブは名前だけだった。イベントのタイルは絵文字で見分けているので、タブも絵文字があると見つけやすい。

## 決定
- カテゴリに、絵文字を1つ付けられるようにする。**付けなくてもよい**（今までのカテゴリは絵文字なしのまま）
- 付けた絵文字は、ホームのタブと、イベントの追加・編集シートのカテゴリ欄で、名前の前に表示する
- カテゴリの管理シートで、名前の左に絵文字の欄を置く。追加するときにも、後からでも、付けたり外したりできる
- 入力の仕方と判定は、イベントのアイコン（決定 035）と同じ。絵文字キーボードから1つ入れ、サーバーで「絵文字1つ」であることを確かめる
- 絵文字は飾りとして扱い、読み上げ（スクリーンリーダー）ではカテゴリ名だけを読む

## 理由
- 必須にしなかったのは、名前だけで足りる人に手間を増やさないため
- 名前の中に絵文字を書いても似たことはできるが、名前は 20 文字までで、並びや見た目がそろわない。別の項目にすれば、表示のしかたを後から変えられる
- おすすめの一覧は置かなかった。カテゴリは数が少なく、作る回数も少ないので、入力欄だけで足りる

## 影響・トレードオフ
- カテゴリの管理シートの1行に欄が1つ増え、幅 320px の画面では名前の欄が狭くなる（#29 とあわせて見る）
- 絵文字の見た目は OS によって違う（#35 と同じ）
