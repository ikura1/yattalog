# 048. 経過時間には「前」を付けて「N日前」と表示する

- 日付：2026-10-13
- 状態：決定（SPEC 3.3 の表示ルールを変更。034 の言い方も合わせる）

## 背景
タイルの経過時間は、「1日」「32日」「2か月」「11時間」のように、数字と単位だけで出していた。
実際に使ってみると、「1日」は「1日おき」「あと1日」のようにも読めて、「前回からどれくらいたったか」だと一目では分かりにくかった。

## 決定
- 数字のあとに「前」を付ける：「11時間前」「1日前」「32日前」「13か月前」「2年前」
- 「さっき」「今日」「まだ」は、そのまま
- 見た目は、数字を大きく、「日前」「時間前」「か月前」「年前」を小さく添える（今までの単位の位置）
- 読み上げは、「5日前にやった」「3時間前にやった」「さっきやった」「今日やった」にそろえる（今までは、日数だけ「前回から5日」だった）
- ログイン画面の見本のタイル、イベントの追加シートの説明も、同じ言い方にする

## 理由
- Yattalog は、期限や間隔を持たない（決定 007）。「前」があれば、過去の話だとすぐ分かり、期限のようには読めない
- 「さっき」「N時間前」「N日前」と、言い方がそろう
- 単位は小さい文字なので、1〜2文字増えても、幅 320px のタイルに収まる（「11時間前」「13か月前」で確認）

## 影響・トレードオフ
- 文字が少し増える。数字の大きさは変えていないので、ひと目で読めるのは今までどおり数字
- 「今日」だけは「前」が付かない（時刻なしで記録した日。何時間前かが分からないため）
