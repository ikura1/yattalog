# 012. 過去の日付で記録できるようにし、時刻は任意にする

- 日付：2026-10-10
- 状態：決定（保存形式は 023 で置き換え）

## 背景
PoC v0.1 では、長押しシートの日時入力（datetime-local）でしか過去の日時を記録できなかった。
スマホの日時ピッカーは操作が重く、「昨日やった」を記録するだけでも手間がかかった。
また、新しく追加したイベントは必ず「まだ」から始まるため、アプリを入れる前の実績を反映できなかった。

## 決定
- 長押しシートに「今／昨日／一昨日／日付を選ぶ」のチップを置く
- 過去の日付の記録では時刻を任意にする。時刻を入れない場合は**時刻なし**の記録として扱う
- イベント詳細のカレンダーで日付をタップすると、その日の分を記録できるようにする
- イベント追加時に「前回やった日（わかれば）」を任意で入力できるようにする
- 未来の日時は記録できない

## 理由
- 過去の分を記録するとき、大半は「昨日」か「一昨日」なので、ワンタップで選べるようにした
- 何時にやったかまでは覚えていないことが多い。時刻の入力を強制すると、適当な値が入ってデータの意味が薄れる
- カレンダーは「いつやったか」を見る場所なので、そこから記録できるのが自然

## 影響・トレードオフ
- 記録に「時刻なしフラグ」を持たせる。時刻なしの記録は、内部ではその日の 12:00（Asia/Tokyo）として保存し、表示では日付だけを出す
- 平均間隔や経過日数は暦日で計算するので、時刻なしの記録があっても結果は変わらない
- 同じ日に、時刻ありと時刻なしの記録が混在したときの並び順は、内部の時刻（12:00）に従う
