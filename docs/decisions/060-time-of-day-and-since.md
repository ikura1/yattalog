# 060. よくやる時間帯と、はじめての記録からの長さを出す

- 日付：2026-10-14
- 状態：決定

## 背景
統計にあったら面白い指標を挙げ、Yuki さんと「前向きに、ゆるく」読めるものから2つを選んだ。

## 決定
### よくやる時間帯（ふりかえり）
- ふりかえり画面の「よくやる曜日」の下に、時間帯ごとの回数を棒グラフで出す。上のタブで絞ったイベントにも効く
- 4つに分ける：朝（4〜11時）、昼（11〜16時）、夕方（16〜19時）、夜（19〜4時）
- **時刻つきの記録だけ**を、記録したときのタイムゾーンの時刻で数える（日付だけの記録は時刻がわからない）。画面にもそう書く
- 見出しの決め方は、よくやる時期・曜日と同じ（最多の7割以上を挙げる）。時刻つきの記録が3回未満なら「時刻つきの記録が増えると、よくやる時間帯がわかります」
- 期間は草と同じ1年分

### はじめての記録から（イベント詳細）
- 統計の下に「はじめての記録 2025年8月3日（1年2か月前）」と出す
- 長さは「今日」「9日前」「10か月前」「1年前」「1年2か月前」のように言う（30日を超えたら月で、12か月を超えたら年と月で）

## 見送ったもの
- 一番のペースだった時期、今年いちばんやったこと、はじめてやった数、合計の時間：あとから足せる
- 前回より間隔が延びた・縮んだ、達成率：「サボっている」と読めたり、目標を決めない方針に合わなかったりする

## 影響・トレードオフ
- 時間帯は、1年分の時刻つきの記録を読んで Python で数える（タイムゾーンが記録ごとに違うため）。多くても数千件なので問題にならない
- 曜日と時間帯の棒グラフは、同じ部品（`templates/web/_tendency.html`、`presenters.tendency_bars()`）で描く
