# 009. はじめて使うときはテンプレートから選ぶ

- 日付：2026-10-10
- 状態：決定

## 背景
汎用アプリなので、登録直後の空のホーム画面だと「何を記録すればいいか」が分かりにくい。

## 決定
登録直後に、テンプレートの一覧からチェックを付けてイベントをまとめて追加できる画面を出す。飛ばすこともでき、後から開くこともできる。

## 理由
最初の画面が空でなくなり、具体例を見ることでアプリの使い方もすぐに伝わる。

## 影響・トレードオフ
- テンプレートは、v1 ではコード内の固定データとして持つ。管理画面で編集できるようにするのは後回し
- 将来、多言語に対応する場合は、テンプレートも翻訳の対象になる
