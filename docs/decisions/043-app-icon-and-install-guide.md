# 043. アプリのアイコンを決め、ホーム画面への追加を案内する

- 日付：2026-10-12
- 状態：決定（031 の実装。#32 のうちアイコンの部分）

## 背景
031 で、ホーム画面への追加（PWA）を案内すると決めた。作ろうとした時点で、アプリのアイコンも、アプリとして追加するための情報（マニフェスト）もなかった。

## 決定
### アイコン
- デザイナーの案を採用する：**緑（#1F6F5C）の地に、色つきのタイルが4枚（空・ぶどう・若葉・ひまわり）、右下の1枚にチェック**
- 小さいサイズ（32px 以下、ブラウザのタブ）は、**タイル1枚とチェック**に簡略化する（4枚だとチェックがつぶれるため）
- 影・グラデーション・つやは付けない
- 元データは SVG（`static/icons/*.svg`）。PNG は `tools/build_icons.py` で作り直せる
  - `icon.svg`：角の丸い版（192・512px）
  - `icon-maskable.svg`：端まで塗り、絵を中央の円（直径 80%）に収めた版（Android が丸や角丸に切り抜くため）
  - `icon-square.svg`：端まで塗った版（iOS のホーム画面用。OS が角を丸める）
  - `favicon.svg`：小さいサイズ用
- いまの SVG は、デザイン案の画像を見て描き起こしたもの。デザイナーから元データが届いたら差し替える

### マニフェストと案内
- `/manifest.webmanifest` を返す（表示はスタンドアロン、開始は `/`）
- ホームの上部にバナー「ホーム画面に追加すると、1タップで開けます」を出す
  - iOS の Safari：手順（共有ボタン → ホーム画面に追加 → 追加）を示すシートを開く
  - iOS のほかのブラウザ：Safari で開き直すよう案内する
  - Android・パソコン：ブラウザが「追加できる」と知らせてきたときだけバナーを出し、ボタンでブラウザの追加ダイアログを開く
- ホーム画面から開いているときは出さない。閉じたら7日間は出さない。3回閉じたら、それ以降は出さない（端末ごとに、ブラウザのストレージで数える）
- メニューの「ホーム画面に追加する方法」から、いつでも手順を開ける

## 見送ったもの
- **Service Worker（オフラインで画面を開けるようにする仕組み）は、今回は入れない**。キャッシュの扱いを誤ると、共用の端末でほかの人のデータが見えるおそれがある（#5）。別に、慎重に進める
- 「テンプレート選択の直後にも、1度だけ案内を出す」（031）は入れていない。テンプレートを専用の画面にしなかった（042）ので、ホームのバナーがそのまま見える
- 起動画面、ロゴの文字つき版の差し替え、単色版は、デザイナーの元データが届いてから（#32）

## 影響・トレードオフ
- Service Worker がないので、オフラインでは画面を開けない（SPEC 3.12 の「シェルはオフラインでも開ける」は未対応のまま）
- iOS では、追加できるかどうかをブラウザが教えてくれない。端末の種類だけを見て案内を出すので、すでに追加済みでも、Safari で開いたときには案内が出る（閉じれば7日間は出ない）
- ログアウトすると、端末に残したデータを消すので、閉じた回数も 0 に戻る
- アイコンを変えても、すでにホーム画面に追加した人の端末では、すぐには変わらないことがある
