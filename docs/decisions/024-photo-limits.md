# 024. 写真は端末で縮小し、1ユーザー1GBまでとする

- 日付：2026-10-10
- 状態：決定（029 で補強）

## 背景
写真の保存にはお金がかかり、不正利用の対象にもなりうる。どこまで許すかの基準を決める必要があった。

## 決定
- 1記録につき1枚。端末で長辺1600px・WebP（または JPEG）・画質80%程度に縮小してからアップロードする（1枚150〜400KB程度）
- 1ユーザーあたりの保存量の上限は1GB。上限に達したら写真だけ追加できなくする
- アップロードは1日100枚まで
- 写真は非公開で保存し、署名付き URL で配信する。EXIF は削除する

## 理由
- 記録のための写真なので、長辺1600pxあればスマホでの閲覧には十分
- 費用の見積もり（Cloudflare R2：保存 $0.015/GB・月、毎月10GBまで無料、転送料は無料）
  - 1,000人が平均100MBずつ使った場合：約100GB → 月 $1.35 ほど
  - 1,000人全員が上限の1GBまで使った場合：約1TB → 月 $15 ほど
  - 上限があれば、最悪の場合でも費用を見積もれる
- 1GBあれば、毎日1枚撮っても約10年分になる。普通の使い方で上限に届くことはない

## 影響・トレードオフ
- 元の画質の写真は保存しない（書き出しで得られるのも縮小後の写真になる）
- 端末側で縮小するので、サーバーの処理負荷は小さい。ただし、サーバー側でもサイズと形式を検証する
- 上限やアップロード制限の値は、運用しながら見直す
