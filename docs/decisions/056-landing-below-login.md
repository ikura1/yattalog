# 056. ログイン画面の下に、はじめて来た人向けの説明を置く

- 日付：2026-10-14
- 状態：決定（030 でランディングページは v1 としていたものを、小さく前倒しする）

## 背景
シェアを β に入れた（決定 053）。投稿にはアプリの URL が付くので、Yattalog を知らない人が、ログイン画面に来るようになる。
ログイン画面には、ロゴと3行の説明と、見本のタイル3つしかなかった。何ができるのか、自分のデータがどう扱われるのかが、伝わらない。

## 決定
- **最初の画面は変えない**（ロゴ、ひとこと、見本のタイル、「Google でログイン」）。知っている人は、今までどおりすぐ入れる
- その下に、説明を足す
  - **どんなアプリ？**：3つの場面を、小さな見本つきで
    1. やったら、タイルを1タップ
    2. 前にやったのは、いつ？
    3. やったことを、シェア
  - **大事にしていること**
    - 期限も通知もありません
    - データは、あなたのもの（いつでも書き出せて、退会すれば、その場ですべて消える）
    - 無料です（広告なし。試験公開中で、登録は先着◯人まで）
  - いちばん下にも「Google でログイン」を置く
- 見本は、画像ではなく、アプリと同じ部品（色つきのタイルなど）を小さく描く。画面の見た目を変えても、古い画像が残らない
- 人数の上限は、設定の値（`MAX_USERS`）をそのまま出す

## 理由
- 専用のランディングページを作ると、URL が1つ増え、ログイン画面との行き来が要る。β の規模では、1枚にまとめるほうが軽い
- 「期限も通知もない」「データを消せる」は、ほかの習慣アプリとの違いであり、知らない人が登録を決めるときの安心材料になる
- 書いた約束は、すべて実装済みのもの（書き出し 039、退会 040、通知なし 007）

## 影響・トレードオフ
- ログイン画面が長くなる。最初の画面は1画面に収めたまま、下へ続く形にした
- 見本は絵文字を使うので、端末によって見た目が変わる（#35）
- 本格的なランディングページ（使い方の動画、よくある質問など）は、v1 で考える
