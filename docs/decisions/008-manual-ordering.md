# 008. ホームの並び順は手動

- 日付：2026-10-10
- 状態：決定（010 で具体化）

## 背景
ホームの並び順を、自動（経過時間順）にするか、ユーザーが手動で並べるかを決める必要があった。

## 決定
- ユーザーがドラッグで並べ替える。自動では並び替えない
- 新しく作ったイベントは先頭に追加する
- 誤操作を防ぐため、並べ替えは「並べ替えモード」の中だけで行う

## 理由
並びが固定されていれば、「あれは上から3番目」と場所で覚えられ、記録するまでの操作が速くなる。
また、自動で並び替えると、記録した瞬間にカードが移動してしまい、操作中に混乱する。

## 影響・トレードオフ
- イベントには並び順の値を持たせる。将来の共有を考えて、並び順はスペース単位にする（ステップ4で決める）
- イベント数が多くなると、目的のイベントを探しにくくなる。その対策はタグや検索で行う（ステップ3・4で決める）
