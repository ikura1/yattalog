# 035. アイコンはすべての絵文字から選べるようにする（キーボードで入力）

- 日付：2026-10-11
- 状態：決定（010 のアイコンの選び方に追加）

## 背景
α では、アイコンを 24 個の決まった絵文字から選ぶだけだった。実際に使うと、イベントに合うものが無いことが多い。
絵文字として使えるものは、ひととおり選べるようにしたい。

## 決定
- イベントの追加・編集シートに「ほかの絵文字を使う」という入力欄を足す。スマホの絵文字キーボードから1つ入れる
- 今までの一覧は「おすすめ」として残す。入力欄とおすすめは、どちらか一方だけが選ばれた状態になる
- 入力欄には絵文字を1つだけ残す（続けて打ったら最後の1つに置き換える）
- サーバーで「絵文字1つ」であることを確かめる（決定 029）。見た目の1文字（書記素）で、絵文字として表示できる文字を含むこと。国旗、肌の色、家族などの組み合わせ絵文字も1つとして扱う
- 判定には `regex` ライブラリ（Unicode の書記素と絵文字の属性を扱える）を使う

## 理由
- アプリの中に全絵文字（約1,900個）の一覧と検索を作る案もあったが、絵文字のデータを同梱して更新し続ける必要があり、日本語での検索まで作ると量が大きい
- OS のキーボードには、検索・最近使った絵文字・肌の色の選択がすでにあり、使い慣れている。新しい絵文字にも OS の更新だけで対応できる
- 一覧を 100 個ほどに増やすだけの案は、欲しいものが無いことが残る

## 影響・トレードオフ
- 入力欄をタップしたあと、キーボードを絵文字に切り替えるひと手間がある（入力欄の下に案内を出す）
- PC では、OS の絵文字パネル（Windows は Win + .、Mac は Ctrl + Cmd + Space）を使う
- 絵文字の見た目は OS によって違う（#35 と同じ）。古い OS では、新しい絵文字が表示できないことがある
- 依存ライブラリが1つ増える（`regex`）
- これから追加される絵文字も、Unicode が絵文字用に予約している範囲であれば受け付ける
