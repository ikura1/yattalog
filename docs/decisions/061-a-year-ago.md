# 061. ふりかえりに「1年前の今ごろ」を出す

- 日付：2026-10-15
- 状態：決定

## 背景
「前にやったのいつだっけ？」を思い出すのが、このアプリの軸。統計の候補に挙げた「去年の今ごろ」を、ふりかえり画面に入れる。

## 決定
- ふりかえり画面の草の下に「1年前の今ごろ」を出す。1年前の同じ日の**前後3日**にやったことを、イベントごとにまとめる（「☀️ 布団を干す　10月13日・10月17日」）
- 回数の多いイベントから並べる。同じなら、先にやった順
- 上のタブでイベントを絞っていれば、そのイベントだけ
- 何もなければ、出さない（「1年前は何もしていません」のような言い方はしない）
- 2月29日の1年前は、前の年の2月28日として数える
- アーカイブしたイベントの記録も出す（ふりかえりの「すべて」と同じ）
- 処理は `services/review.py` の `a_year_ago()`

## 見送ったもの
- ホームに出す：ホームは記録のための画面なので、増やさない
- 2年前・3年前：記録がたまってから考える
