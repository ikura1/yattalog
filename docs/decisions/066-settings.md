# 066. 設定の画面を作る（週の始まり、見た目、押したときの震え、タイムゾーン）

- 日付：2026-10-20
- 状態：決定（015 の「週は月曜始まり」を、選べるようにする）

## 背景
設定の画面がなかった。あったら嬉しいものを挙げ、Yuki さんと「価値があるもの」を選んだ。あわせて、週の区切りが画面によってそろっていなかった（連続記録は月曜始まり、カレンダー・ふりかえりの草・よくやる曜日は日曜始まり）。

## 決定
メニューに「設定」の組を足し、そこから開く。保存すると「保存しました」と知らせる。
- **週の始まり**（月曜／日曜、既定は月曜＝決定 015 のまま）
  - 連続記録の区切りと、カレンダー・ふりかえりの草・よくやる曜日の並びを、すべてこれにそろえる
  - 値はスペース（`Space.week_start`）に持つ。記録の持ち主の単位なので、将来、共有のスペースでも同じ区切りになる
  - 変えたら、そのスペースのイベントの連続記録を数え直す（`events.set_week_start()`）
  - これまで日曜始まりで出していたカレンダー・草・曜日の棒グラフは、既定の月曜始まりに変わる
- **見た目**（端末と同じ／明るい／暗い、既定は端末と同じ）：`User.theme`。選んでいれば `<html data-theme>` に印を付け、CSS は端末の設定より優先する。保存したら、その場で変わる
- **押したときの震え**（オン／オフ、既定はオン）：`User.haptics`。オフなら `<body data-haptics="0">` で、JS が震えさせない
- **タイムゾーン**：一覧から自分で選べる（これまでは、端末とずれたときの提案だけ）。よく使うものを先に並べる

## 見送ったもの
- 通知・リマインダー：急かす方向になる。入れるなら最初はオフで、別に考える
- ホームの自動の並べ替え：自分で並べた順を大事にする作りのため
- 取り込み：v1 では作らない

## 影響・トレードオフ
- 新しい列：`Space.week_start`、`User.theme`、`User.haptics`（どれも既定値つきで足すだけ）
- 連続記録の計算に、スペースの週の始まりを渡す（`period_index`・`compute_streak`・`streak_state` に引数を足した。既定は月曜）
