# 050. カテゴリに入っていないイベントは、「カテゴリなし」のタブで見られるようにする

- 日付：2026-10-13
- 状態：決定（013 のカテゴリとタブに追加）

## 背景
カテゴリを使い始めると、「まだどのカテゴリにも入れていないイベント」を探す手段がなかった。「すべて」のタブで、1つずつ見て探すしかない。

## 決定
- タブ列の最後（「＋」の手前）に、**「カテゴリなし」**のタブを出す
- 出すのは、**カテゴリが1つ以上あり、かつ、カテゴリに入っていないイベントが1件以上あるとき**だけ
- 開くと、カテゴリに入っていないイベントだけが並ぶ。ほかのタブと同じく、件数を出す
- このタブを開いているときに追加したイベントは、カテゴリなしになる
- データは変えない。カテゴリを持たないイベントを、見せ方で絞るだけ

## 検討した案
| 案 | 見送った理由 |
|---|---|
| 「その他」というカテゴリを、はじめから作っておく | カテゴリを使わない人にも、タブが増える。「その他」を消したり名前を変えたりしたときの扱いが要る。「入れていない」と「その他に入れた」の区別がつかなくなる |
| 検索や絞り込みの画面を足す | イベントの数は多くても数十で、タブで足りる。画面が1つ増える |
| **「カテゴリなし」のタブ**（採用） | データを変えずに済み、要るときだけ出る |

## 理由
- カテゴリは任意（0〜1個）という作り（013）を変えずに済む
- カテゴリを使っていない人には、何も増えない
- 整理し終わる（全部がカテゴリに入る）と、タブは自然に消える

## 影響・トレードオフ
- 最後の1件をカテゴリに入れると、タブが消える。そのとき開いていたら、「すべて」に戻る
- イベントの追加・編集シートのカテゴリ欄は「なし」のまま（短い欄なので）。タブは、何が「なし」なのかが分かるよう「カテゴリなし」とした
