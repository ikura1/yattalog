# 031. ホーム画面への追加（PWA）を案内する

- 日付：2026-10-10
- 状態：決定

## 背景
003 で「PWA としてホーム画面に追加して使う」前提にしたが、追加の方法を案内する仕様がなかった。
特に iOS の Safari では、共有メニューの奥に操作が隠れていて分かりにくい（仕様レビュー P2・D1）。

## 決定
- ブラウザで開いていて未追加のときは、ホームの上部に小さなバナーを出す
- Android ではブラウザの追加ダイアログを開く。iOS では手順を図で示す。iOS の Safari 以外のブラウザでは、Safari で開き直すよう案内する
- 閉じたら7日間は出さない。3回閉じたら出さない。テンプレート選択の直後にも1度だけ出す

## 理由
- ホーム画面から1タップで開けることが「すぐ記録できる」という価値の前提であり、追加してもらえないとその価値が伝わらない

## 影響・トレードオフ
- 何度も出すとうるさく感じられるので、表示の回数と間隔を制限した
- 追加の有無は端末ごとに異なるので、この判定は端末側（ブラウザのストレージ）で行う
