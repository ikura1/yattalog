# 014. 毎日続いているイベントに連続記録バッジを出す

- 日付：2026-10-10
- 状態：決定（015 で拡張）

## 背景
毎日やっていることについては、Streaks のように「続いている」ことが見えると気持ちがいい。
一方で 007 では、「やらなきゃ」というプレッシャーを与えないために、目安の間隔を持たせないと決めている。

## 決定
- 暦日で2日以上続けて記録しているイベントには、タイルの右上に「🔥N」を出す
- 今日の記録がまだでも、昨日まで続いていれば薄く表示する
- 連続日数が増えた瞬間は、バッジのアニメーションとトーストで祝う
- 途切れたことは通知もメッセージもしない。バッジが消えるだけにする

## 理由
- 記録したことへのご褒美（気持ちよさ）になる。プレッシャーにはしない
- 連続は記録から自然に生まれるもので、目標を設定する必要がない。そのため 007 と矛盾しない

## 影響・トレードオフ
- 毎日やるものではないイベント（散髪など）には、このバッジは出ない。これは意図どおり
- 「最長連続記録」はまだ表示しない。欲しくなったら統計（011）に追加する
- 過去の日付での記録でも連続を作れる。自己申告のアプリなので、これは許容する
