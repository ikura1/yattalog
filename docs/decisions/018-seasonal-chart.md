# 018. イベント詳細に「よくやる時期」（月別の棒グラフ）を追加する

- 日付：2026-10-10
- 状態：決定

## 背景
011 では、統計をカレンダー・記録回数・平均間隔の3つに絞った。
その後、「どの時期によく記録しているか」も年単位で見たい、という要望が出た。

## 決定
- イベント詳細に、月別の記録回数を棒グラフで表示する
- 「年ごと」と「全期間（月別合計）」を切り替えられるようにする
- 最大回数の7割以上ある月を「よくやる時期」として、文章の見出しにする

## 理由
- 季節によって頻度が変わるイベント（エアコン掃除、布団干しなど）では、季節のくせが一目で分かる
- 年ごとに見られるので、前の年と比べることもできる
- 見出しを文章にしておくと、グラフを読まなくても結論が伝わる

## 影響・トレードオフ
- 011 の「統計は3つ」を拡張する（ほかの3つはそのまま）
- 毎日やるイベントでは、どの月もほぼ同じ高さになる。その場合は「1年を通して同じくらい」と表示する
- 「7割」というしきい値は PoC で様子を見て調整する
- 曜日別の傾向（「週末に多い」など）や、GitHub 風の年間ヒートマップは今回は入れない。必要になったら検討する
