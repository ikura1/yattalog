# 023. タイムゾーンはユーザーごとに持ち、時刻なしの記録は日付で保存する

- 日付：2026-10-10
- 状態：決定

## 背景
これまでの仕様では Asia/Tokyo に固定していた。一般公開すると、海外のユーザーや旅行中の利用もある。

## 決定
- ユーザーごとにタイムゾーン（IANA 名）を持つ。初回ログイン時に端末の設定から決める
- 端末のタイムゾーンと設定が違うときは、切り替えるかどうかを聞く（自動では切り替えない）
- 日付の区切り（経過日数・連続記録・統計）は、今のタイムゾーン設定で計算する
- 時刻ありの記録は UTC の瞬間として保存する。時刻なしの記録は「日付」として保存する

## 理由
- 旅行中は一時的にタイムゾーンが変わるだけのことが多い。自動で切り替えると、日付がずれて混乱する
- 時刻なしの記録を「その日の12時」のような瞬間で保存すると、タイムゾーンを変えたときに日付がずれてしまう。日付として持てば、ずれない

## 影響・トレードオフ
- 012 で「内部では 12:00 として保存」としていた点を、この決定で置き換える
- 記録のデータには、日時（時刻ありの場合）と日付（時刻なしの場合）のどちらかが入る形になる（ステップ4）
- タイムゾーンを変えると、時刻ありの記録が属する日付が変わることがある。これは仕様として受け入れる
