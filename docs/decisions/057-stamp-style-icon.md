# 057. アプリのアイコンを「スタンプ風」に変える

- 日付：2026-10-14
- 状態：決定（043 のアイコンの絵を置き換える。ファイルの構成とマニフェストは 043 のまま）

## 背景
043 で入れたアイコン（緑の地に色つきのタイル4枚、右下の1枚にチェック）は、Yuki さんが見て「なんかイマイチ」だった。代わりの案を並べて比べ、Yuki さんが別に用意した「スタンプ風」の案に変えることにした。

4枚のタイルの絵には、次の弱さもあった。
- ホーム画面の大きさ（46〜60px）では、何の絵か分かりにくい
- 小さいサイズではチェックがつぶれるので、タブ用だけ別の絵（タイル1枚）にしていた

## 決定
- **緑（#1F6F5C）の地に、少し傾いたクリーム色（#FFF6D6）の、丸みのある四角と緑のチェック。右上に「ぽん」と押した勢いを表す短い線が3本**
- 「やった！の気持ちを、ぽんっと」押すハンコのイメージ。タイルをタップしたときに出る「✓」のスタンプと同じ気分にそろえる
- 大きいサイズとタブ用で、同じ絵を使う。タブ用（`favicon.svg`）は絵を少し大きくし、線を太くしてつぶれないようにする
- Android 用（`icon-maskable.svg`）は、絵を中央の円（直径 80%）に収める（043 と同じ）
- 影・グラデーション・つやは付けない（043 と同じ）

## 見送ったもの
- 単色版（黒・白抜き）と、ロゴの横組み（アイコン＋「Yattalog」）。使う場所（通知など）がまだないので、要るようになったときに作る

## 影響・トレードオフ
- すでにホーム画面に追加した人の端末では、アイコンがすぐには変わらないことがある（043 と同じ）
- リンクのプレビュー画像（`og.png`）も、新しいアイコンで作り直した

## 追記（2026-10-14）：デザイン案に合わせて描き直す
最初に入れた絵は、Yuki さんのデザイン案（A案：スタンプ風）と形が少し違っていた（スタンプが角丸の正方形で、小さく、傾きが大きい。線も細い）。案に合わせて描き直した。

- スタンプは、辺が少しふくらんだ、ゆがみのある四角にする（手で押した感じ）。傾きは 8 度。案と同じく、絵を大きく、チェックと3本の線を太くする
- **外側の形も、案と同じ、少しゆがんだ丸い四角にする**。ただし、そのままの形で出る場所だけ（`icon.svg`・`favicon.svg`：ブラウザのタブ、アプリの中、オフラインの案内）。ホーム画面用（`icon-square.svg`・`icon-maskable.svg`）は、OS が角丸や円に切り抜くので、いままでどおり端まで塗る
- 4つの SVG は、`tools/draw_icons.py` で同じ絵から書き出す（手で4つを直すと、ずれるため）。デザイナーから SVG の元データが届いたら、それに差し替える
- **ログイン後のホームの、タイトル「Yattalog」の左に、アイコンを出す**（28px）。飾りなので、読み上げには出さない（`alt=""`）
