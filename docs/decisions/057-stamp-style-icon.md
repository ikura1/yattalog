# 057. アプリのアイコンを「スタンプ風」に変える

- 日付：2026-10-14
- 状態：決定（043 のアイコンの絵を置き換える。ファイルの構成とマニフェストは 043 のまま）

## 背景
043 で入れたアイコン（緑の地に色つきのタイル4枚、右下の1枚にチェック）は、Yuki さんが見て「なんかイマイチ」だった。代わりの案を並べて比べ、Yuki さんが別に用意した「スタンプ風」の案に変えることにした。

4枚のタイルの絵には、次の弱さもあった。
- ホーム画面の大きさ（46〜60px）では、何の絵か分かりにくい
- 小さいサイズではチェックがつぶれるので、タブ用だけ別の絵（タイル1枚）にしていた

## 決定
- **緑（#1F6F5C）の地に、少し傾いたクリーム色（#FFF8DC）の角丸の四角と緑のチェック。右上に「ぽん」と押した勢いを表す短い線が3本**
- 「やった！の気持ちを、ぽんっと」押すハンコのイメージ。タイルをタップしたときに出る「✓」のスタンプと同じ気分にそろえる
- 大きいサイズとタブ用で、同じ絵を使う。タブ用（`favicon.svg`）は絵を少し大きくし、線を太くしてつぶれないようにする
- Android 用（`icon-maskable.svg`）は、絵を中央の円（直径 80%）に収める（043 と同じ）
- 影・グラデーション・つやは付けない（043 と同じ）

## 見送ったもの
- 単色版（黒・白抜き）と、ロゴの横組み（アイコン＋「Yattalog」）。使う場所（通知など）がまだないので、要るようになったときに作る
- 外側の形を、角丸の四角でなく手描き風のゆがんだ形にすること。OS が角丸や円に切り抜くので、地は四角で塗る

## 影響・トレードオフ
- すでにホーム画面に追加した人の端末では、アイコンがすぐには変わらないことがある（043 と同じ）
- リンクのプレビュー画像（`og.png`）も、新しいアイコンで作り直した
