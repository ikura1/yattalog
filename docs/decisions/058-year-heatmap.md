# 058. ふりかえり：1年の「やった日」を草のように並べる

- 日付：2026-10-14
- 状態：決定

## 背景
Yattalog は、もともと「やったこと」を記録して、グラフや傾向、履歴を眺めて楽しむためのものだった。イベントごとの統計（回数、平均間隔、よくやる時期、カレンダー）は詳細画面にあるが、**イベントをまたいで、暮らし全体を眺める画面**がなかった。Yuki さんが「1年の草（GitHub のヒートマップ）」を選んだ。

## 決定
- メニューに「ふりかえり」を足す（`/review/`）。12か月分（今月を含む）の「やった日」を、**月ごとの小さなカレンダー**で並べる（日曜始まり。詳細画面のカレンダーと同じ）
- 上に「この12か月で N 回、M 日やった」。やらなかった日数は出さない
- マスの色
  - **すべて**：その日にやった**イベントの種類の数**で濃くする（1つ・2つ・3つ・4つ以上）。同じイベントを何回やっても1つと数える
  - **1つのイベントに絞ったとき**：濃淡はなし。やった日を、そのイベントの色で塗る
- マスを押すと、その日にやったことを下に出す（時刻の順。時刻なしの記録は後ろ）。はじめは今日
- 上のタブで、イベントを1つに絞れる（アーカイブしていないもの）。「すべて」には、アーカイブしたイベントの記録も数える
- 処理は `services/review.py`、マスの組み立ては `presenters.year_months()`

## 見送ったもの
- **横に並べる形（GitHub と同じ並び）**：スマホでは半年ほどしか入らず、横にスクロールが要る。月ごとなら1年分が縦に収まり、日付も分かりやすい（試作で見比べた）
- **回数で濃くする**：ほとんどのイベントは1日に1回なので、差が出ない
- **連続記録（ストリーク）で濃くする**：途切れた次の日から色が薄くなり、途切れたことが目に見えてしまう（決定 007 の「途切れても責めない」に反する）
- **やった日の印を絵文字にする**（1つに絞ったとき）：このアプリらしいが、マスが小さく、実機で見ていないので、まずは色にした
- 過去の年への切り替え、曜日・時間帯の傾向、「去年の今ごろ」、年のまとめ：あとから足せる

## 影響・トレードオフ
- 新しいデータは持たない。毎回、記録から数える（12か月分の、日ごとの集計を1回）
- イベントの色に、草用の濃い色（`--s-*`）を足した。タイルの色（`--t-*`）は薄くて、草のマスでは見分けにくいため
