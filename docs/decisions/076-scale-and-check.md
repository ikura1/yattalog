# 076. 記録のしかたに「段階で選ぶ」と「チェックする」を足す

- 日付：2026-11-17
- 状態：決定

## 背景
決定 075 で、スライダーとチェックは「よく使う数字を使ってみてから」と見送った。
触れる見本を見た Yuki さんから「チェックとスライダーがほしい」と要望があった。ごちゃつかせない、という前提は変わらない。

## 決定
イベントの編集の「数字の記録」を**「記録のしかた」**に改め、選べるものを5つにする：なし／合計を見る／推移を見る／**段階で選ぶ**／**チェックする**。
**1つのイベントに、記録のしかたは1つだけ**。「なし」のほかは、タイルを押すとシートが開く。

### 段階で選ぶ（スライダー）
- 段階は **1〜5 で固定**。範囲も、段階ごとの言葉（「軽い」「つらい」など）も設定しない
- シートにスライダーを出し、前回の段階（なければ 3）に合わせておく。いまの段階を大きな数字で出す
- 記録には、数字（`Log.value`）として残す。詳細は「段階の推移」（推移を見ると同じ：最新・平均・最小・最大・折れ線）。履歴には「4/5」と出す
- 単位は持たない。よく使う数字のボタン（決定 075）は出さない
- スライダーは空にできない。そこで、**段階のない記録を編集するとき**（1タップで付けた記録や、前の記録のしかたで数字を付けた記録）は「段階は付けない」（数字があれば「いまの数字のままにする」）に印を入れて出し、スライダーを動かすまで書き換えない

### チェックする
- イベントごとに、チェックする**項目**を決める。1行に1つ、**8個まで**、1つ **12文字まで**。同じ名前は1つにまとめる。チェックするイベントには、1つ以上が要る
- シートに項目を並べ、**前回と同じものに印を入れておく**。いくつ選んでもよく、選ばなくても記録できる
- 記録には、**項目の名前そのもの**を残す（`Log.checks`、項目の順）。あとで項目の名前を変えたり消したりしても、前の記録は前の名前のまま
- 詳細に「どれを何回」（項目ごとの回数の横棒）を出す。いまはない項目も、回数があれば後ろに出す。履歴には「床・トイレ」と出す
- 項目にないものが送られたら、捨てずに断る（項目を変えたあとの、開いたままのシート）。記録の編集では、その記録に付いている前の名前は残せる
- 記録のしかたをほかに変えても、項目は覚えておく（戻したときに打ち直さなくて済む）。付けたチェックも消さない

### ポリシー
取得する情報に「チェックした項目」が増えるので、プライバシーポリシーを 2026-11-17 に改定する。改定の帯が全員に出る（決定 073）。

## 理由
- 段階を 1〜5 に固定すれば、設定が1つも増えない。決定 075 で見送った理由（イベントごとに範囲の設定が要る）がなくなる。体調や気分の記録（決定 068）には、5段階で足りる
- 段階を数字として持てば、推移の統計・グラフ・書き出しをそのまま使える
- チェックは、名前を記録に残せば、項目の表と ID を持たなくてよい。項目を直しても、過去の記録の意味が変わらない
- 8個・12文字は、スマホのシートで2〜3行に収まる量

## 見送ったもの
- **選ぶ（どれか1つ）**：チェックで1つだけ選べば足りる。記録のしかたを6つにしない
- 段階の範囲や言葉の設定（1〜10、「軽い〜重い」など）：設定が増える。要望が出てから
- 1つのイベントに、数字とチェックの両方：シートがごちゃつく
- チェックを条件にした絞り込みや、項目ごとの「前回からの日数」：使ってみてから
