# 021. データの書き出し（ZIP）と退会時の完全削除に対応する

- 日付：2026-10-10
- 状態：決定

## 背景
一般公開（002）では、ユーザーが自分のデータを持ち出せることと、消せることが必要になる。

## 決定
- 設定から、全データを ZIP（logs.csv、events.csv、data.json、photos/）で書き出せるようにする。作成はバックグラウンドで行い、ダウンロードリンクは7日間有効、1日1回までとする
- CSV は UTF-8（BOM 付き）にする
- 退会すると、イベント・記録・写真・実績・AI 連携をすべて削除する。バックアップからも30日以内に消える
- 退会の前には書き出しを勧め、確認のチェックを入れないと退会できないようにする
- 取り込み（インポート）は v1 では作らない

## 理由
- 自分の記録をいつでも持ち出せることは、長く使ってもらうための安心材料になる
- 退会時にデータを確実に消すことは、個人情報保護法への対応として必要
- CSV なら表計算ソフトで開ける。JSON なら機械的に処理でき、将来の取り込みにも使える

## 影響・トレードオフ
- 書き出し用のバックグラウンド処理（ジョブキュー）が必要になる
- 退会の削除処理は、写真ストレージ（R2）の削除も含めて確実に行い、失敗したら再実行する仕組みが要る
