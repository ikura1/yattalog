# 016. ログインは Google アカウントのみにする

- 日付：2026-10-10
- 状態：決定

## 背景
002 で一般公開を決めたため、アカウントの仕組みが必要になった。Google ログインが使えると嬉しい、という要望があった。

## 決定
- ログイン方法は Google アカウントだけにする（OAuth / OpenID Connect、django-allauth の Google プロバイダを使う）
- メールアドレスとパスワードによる登録は作らない
- Google から受け取るのは、ID・メールアドレス・表示名だけにする

## 理由
- パスワードの保存・リセット、確認メールの送信が不要になり、作るものも守るものも大きく減る
- スマホでは、ほとんどの人が Google アカウントを持っていて、ワンタップで始められる

## 影響・トレードオフ
- Google アカウントを使いたくない人は利用できない。要望が多ければ、Apple ログインやメールのマジックリンクを追加することを検討する
- 002 で挙げた「確認メールとパスワードリセットのためのメール送信」は不要になる。ただし、問い合わせ対応用のメールアドレスは必要
- Google Cloud で OAuth 同意画面を設定し、審査を受ける必要がある（要求するスコープは基本的なものだけ）
- Google アカウントを削除されたユーザーへの対応は、退会とデータ削除の仕様（ステップ5）で決める
