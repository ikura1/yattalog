# 042. テンプレートは、空のホームにそのまま出す

- 日付：2026-10-12
- 状態：決定（009 の出し方を具体化）

## 背景
009 で、「登録直後に、テンプレートの一覧からまとめて追加できる画面を出す。飛ばすこともでき、後から開くこともできる」と決めた。
β では知らない人が使い始める（038）。空のホームだけでは、何をすればいいかが伝わらない。

## 決定
- 専用の画面は作らない。**イベントが1つもないホームに、テンプレートの一覧をそのまま出す**
- 「見たかどうか」「飛ばしたかどうか」は記録しない。イベントが1つでもできれば、一覧は出なくなる
- 「自分で作る」は、イベントの追加シートを開くだけ
- メニューの「テンプレートから追加」で、後からも開ける
- 同じ名前のイベントをもう持っているテンプレートは「追加済み」として、選べないようにする（二重に追加しない）
- テンプレートは、コードの中の固定データ（`apps/events/services/starter.py`）。10個
- 追加したイベントは、ふつうのイベントと同じ。あとから名前・アイコン・色を変えられる

## 理由
- 登録した直後は、必ずイベントが0個。「空のホームに出す」だけで、「登録直後に出す」を満たせる
- 「見たかどうか」を持たないので、項目もマイグレーションも要らず、端末をまたいでも同じように動く
- 画面を移らないので、追加した直後にそのままタイルをタップして、記録を試せる

## 影響・トレードオフ
- イベントをすべてアーカイブ・削除した人にも、また一覧が出る（やり直したい人には、むしろ都合がよい）
- 「飛ばす」という操作はない。使わない人は、一覧を無視して「自分で作る」か「＋ 追加」を押す
- テンプレートを変えるには、コードを直してデプロイする
- 多言語に対応するときは、テンプレートも翻訳の対象になる（009 のとおり）
