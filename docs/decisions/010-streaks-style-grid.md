# 010. ホームは Streaks 風のアイコングリッドにする

- 日付：2026-10-10
- 状態：決定

## 背景
TimeTask は、もともと習慣化アプリ **Streaks** を参考にしつつ、自分が使いやすい形にしたいという動機で作り始めた。
ステップ2まではリスト型のホームを前提に決めていたので、ホームの見た目を改めて決めた。

## 決定
- ホームは、イベントを**アイコン（絵文字）と色付きのタイルで並べたグリッド**にする
- タイルには、経過日数を一番大きく表示する
- 操作の割り当ては 006 のままにする（タップで記録、長押しで詳細）。Streaks の「長押しで完了」は採用しない
- 006 と 008 を次のように具体化する
  - 長押しで開くシートには、詳細な記録フォームに加えて「履歴・統計を見る」と「編集」を入れる
  - 008 の「並べ替えモード」は「**編集モード**」に広げる。編集モードでは並べ替え、詳細を開く、アーカイブと削除ができる。これを長押しを使わずに詳細へ行く経路にもする

## 理由
- 位置とアイコンでイベントを覚えられるので、探さずにすぐ記録できる
- 記録はできるだけ速くしたいので、タップで記録する方を選んだ。誤タップは「取り消す」で戻せる

## 影響・トレードオフ
- イベントにアイコンと色の項目が必要になる（ステップ4）
- タイルは情報量が少ないので、コメントなどは詳細画面で見ることになる
- タイルの面積が小さいため、スクロールしようとしたタッチが記録になってしまわないように、タップ判定を慎重に作る
