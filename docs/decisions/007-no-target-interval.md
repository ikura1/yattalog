# 007. 目安の間隔（期限）は持たせない

- 日付：2026-10-10
- 状態：決定

## 背景
「2週間ごと」のような目安の間隔をイベントに持たせて、「そろそろ」「過ぎている」を表示する案があった。

## 決定
目安の間隔は持たせない。表示するのは経過時間（前回から○日）だけにする。

## 理由
Yattalog は ToDo アプリではなく記録アプリなので、「やらなきゃ」というプレッシャーを与えたくない。

## 影響・トレードオフ
- 「そろそろやるべきもの」を自動では教えない。気付くかどうかはユーザー次第になる
- 将来、通知やリマインド機能を検討するときは、この決定を見直すことになる
