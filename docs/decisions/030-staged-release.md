# 030. α・β・一般公開の3段階でリリースする

- 日付：2026-10-10
- 状態：決定

## 背景
v1 に入れる予定の機能が増えた（実績、シェア、季節グラフ、書き出し、タイムゾーン、カテゴリ、連続記録の単位など）。
一度にすべてを作ってから公開すると、公開までが長くなり、方向を修正する機会も遅れる（仕様レビュー P1）。

## 決定
- **α（自分だけ）**：記録まわりの中心となる機能と、Google ログイン
- **β（知人10〜20人）**：テンプレート、PWA の追加案内、写真、書き出し、退会、規約とポリシー、意見を送る窓口
- **v1（一般公開）**：シェア、実績、よくやる時期、ランディングページ
- **v1.x**：MCP、記録用 URL、オフラインでの記録
- 各段階の内訳は SPEC 7章のとおり。段階が終わるごとに実際に使ってみて、仕様を見直す

## 理由
- まず自分で毎日使ってみることで、記録の気持ちよさという中心の価値を早く確かめられる
- 一般公開に必要なもの（規約、退会、書き出し）は、他人に使ってもらう β の時点でそろえれば足りる

## 影響・トレードオフ
- α の時点ではデータの書き出しも退会もないので、使うのは自分だけに限る
- 段階ごとにデプロイと確認の手間がかかる
