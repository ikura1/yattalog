# 003. スマホ中心・PWA で作る

- 日付：2026-10-10
- 状態：決定

## 背景
記録するのは「やった直後」であることが多く、そのときはたいていスマホを手にしている。

## 決定
- スマホでの使い勝手を最優先にして設計する
- PWA（マニフェストと Service Worker）に対応し、ホーム画面に追加して使えるようにする
- PC でもレスポンシブ表示で使えるようにする

## 理由
ネイティブアプリより開発と配布のコストがずっと低く、ストア審査もない。
ホーム画面から1タップで開けるので、記録の手軽さはネイティブアプリとほとんど変わらない。

## 影響・トレードオフ
- 主要な操作は、親指の届く範囲（画面の下側）に置く
- iOS の Web プッシュ通知には制約がある（将来、通知機能を検討するときに考慮する）
- オフラインでの記録に対応するかは、ステップ2・6で決める
