# 011. イベント詳細の統計はカレンダー・記録回数・平均間隔の3つ

- 日付：2026-10-10
- 状態：決定

## 背景
Streaks のように、記録の積み重ねを見られるようにしたい。ただし Yattalog は「連続日数」を数えるアプリではない。

## 決定
イベント詳細に次の3つを表示する。
- カレンダー（記録した日に印を付ける）
- 記録回数（合計と今年）
- 平均間隔（「だいたい2週間ごと」のように丸めて表示する。記録が2回以上あるときだけ）

最長間隔と最短間隔は v1 では表示しない。

## 理由
- 007 で目安の間隔を持たせないと決めたので、その代わりに「実績から分かるペース」として平均間隔を見せる
- 3つあれば十分に振り返りができ、画面も混み合わない

## 影響・トレードオフ
- 平均間隔は、記録日時の差を平均して求める。外れ値（長く放置した期間）があると平均が引っ張られる。中央値を使うかどうかは実装時に、実際のデータで確かめて決める
