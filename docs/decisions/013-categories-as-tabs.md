# 013. カテゴリを1つだけ持たせ、ホームのタブで切り替える

- 日付：2026-10-10
- 状態：決定

## 背景
イベントが増えると、1枚のグリッドでは見通しが悪くなる。
表示の分け方として、セクション（縦に並べて折りたたむ）、タブ（ページを切り替える）、タグによる絞り込みの3案を比べた。

## 決定
- イベントには**カテゴリを0〜1個**持たせる。タグ（複数所属）は採用しない
- ホーム上部に「すべて＋各カテゴリ」のタブを置き、タップかスワイプで切り替える
- 並び順は全体で1つにする。カテゴリのタブで並べ替えた場合は、そのカテゴリ内の順番だけを入れ替える

## 理由
- 1画面に表示するタイルの数が減り、すっきりする。Streaks のページ切り替えにも近い
- 所属先が1つなら「どこに表示されるか」が明確で、手動の並べ替え（008）とも矛盾しない
- タグは横断的に分類できる反面、「どれに付けるか」で迷いやすく、並び順の意味も曖昧になる

## 影響・トレードオフ
- 「家事」と「月1回」のように、2つの軸で分けることはできない。必要になったら、タグを絞り込み専用として別途追加することを検討する
- カテゴリなしのイベントは「すべて」タブにしか表示されない
- データモデル（ステップ4）では、カテゴリをスペースに属させる（004 の共有方針に合わせる）
