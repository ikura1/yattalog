# 020. 実績バッジを入れる（失うものは作らない）

- 日付：2026-10-10
- 状態：決定

## 背景
連続記録（014・015）に加えて、記録を続けることのご褒美として実績バッジを入れたい。

## 決定
- 16種類の実績（通算・連続・イベント・使い方・ちょっと特別）を用意する。一覧は SPEC 3.10 のとおり
- 解除したときはトーストで知らせ、「実績」画面で解除済みと未解除の両方を見られるようにする
- 一度解除した実績は、記録を削除しても取り消さない
- 期限付きの実績や、失うと減るものは作らない

## 理由
- 記録することに小さな楽しみが加わる
- 「使い方」の実績（過去の日付で記録、メモ、写真、シェア）は、機能を知ってもらうきっかけにもなる
- 失うものを作らないので、007 の「プレッシャーを与えない」方針と両立する

## 影響・トレードオフ
- 解除日時を保存するテーブルが必要になる（ユーザー × 実績 × 解除日時）
- 判定は記録の追加時などに行う。過去の日付の記録で条件を満たした場合も解除する
- 実績の種類を増やすときは、既存ユーザーにまとめて解除が起きないよう、判定と通知の扱いを決めてから追加する
