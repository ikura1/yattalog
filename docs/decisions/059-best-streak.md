# 059. イベント詳細の統計に「最高連続」を出す

- 日付：2026-10-14
- 状態：決定

## 背景
連続記録は、いま続いている分しか見えない（途切れたらバッジが静かに消える、決定 007・014）。Yuki さんから「統計に最高連続回数があってもいい」と要望があった。

## 決定
- イベント詳細の統計に「最高連続」（例：「🔥 8週連続」）を足す。これまでで一番長く続いた連続回数
- 数え方は、いまの連続記録と同じ（連続の単位ごとの期間で数え、同じ期間の記録は1回）
- **途切れても減らない**。記録を消したときだけ変わる
- 連続の単位が「なし」のイベントと、2回に届かないときは出さない
- 出すときは、統計のタイルを 2×2 にする（4つ横に並べると、スマホで値が詰まる）
- 毎回、記録から数える（新しい列は足さない）

## 理由
- 「途切れても責めない」方針（決定 007）のまま、続けた手ごたえを残せる。途切れた後も「前は8週続いた」と見えるのは、前向きな情報
- 実績バッジ（SPEC 3.10）の「ずっとつづいてる」とも相性がよい

## 影響・トレードオフ
- 詳細を開くたびに、そのイベントの記録の日付を全部読む。1つのイベントの記録は多くても数千件なので、問題にならない
