# 022. v1 ではオフラインでの記録に対応しない

- 日付：2026-10-10
- 状態：決定

## 背景
電波のない場所（ジムの地下、キャンプ場など）でも記録できると嬉しい。ただし必須ではない。

## 決定
- v1 では、オフラインでの記録には対応しない
- アプリの画面（PWA のシェル）はオフラインでも開けるようにする。オフラインのときは、記録できないことをはっきり表示する
- オフラインで記録をためておき、つながったら同期する機能は v1.x 以降で検討する

## 理由
- 同期・競合・重複への対応が必要になり、作る量に比べて得られる価値が小さい
- 時刻なしの記録や過去の日付での記録（012）があるので、後から記録し直せる

## 影響・トレードオフ
- 電波がない場所では、その場で記録できない
- 後で対応するときに備えて、記録の ID はクライアント側で作れる形（UUID）にしておくと、重複しない同期を実装しやすい
