# 001. TimeTask を Yattalog として作り直す

- 日付：2026-10-10
- 状態：決定

## 背景
2019年に Django 2.1 で作った TimeTask（ikura1/timetask）は、作りかけのまま止まっていた。
開発の途中で、扱っているものが「タスク」ではなく「イベント」だと気付き、名前もしっくりこなくなっていた（旧 Issue #13 #15）。

## 決定
- 新しい名前 **Yattalog（やったログ）** で、新しいリポジトリにゼロから作り直す
- 旧データの移行や後方互換性は考えない
- 仕様もゼロから決め直す。旧実装と旧 Issue は参考資料として扱う

## 理由
- 記録ボタンの「やった！」とそのままつながり、親しみやすい
- 互換性を気にしなくてよいので、設計を自由に決められる

## 影響・トレードオフ
- 旧リポジトリの Issue は引き継がない。必要なものは、このリポジトリで改めて Issue にする
