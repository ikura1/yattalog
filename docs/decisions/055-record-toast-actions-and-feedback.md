# 055. 記録した直後の知らせから、メモ・シェア・詳細へ行けるようにし、手ごたえを足す

- 日付：2026-10-14
- 状態：決定（006・028 の知らせを変更。053 の入口を変更。#33 の一部）

## 背景
- 履歴・統計・シェアは、イベントの詳細にある。そこへ行く道は、「編集モードにしてタイルを押す」か「長押しシートの中のボタン」だけで、気づきにくかった（#33）
- シェアは、記録した直後の知らせからは、連続記録が伸びたときにしか行けなかった。記録した直後が、いちばん人に言いたい瞬間
- タイルを押したときの反応は、見た目の小さな動きだけだった

## 決定
### 知らせ（トースト）
- 記録した直後の知らせに、次の操作への入口を4つ並べる：**取り消す／メモ／シェア／詳細**
  - 文言は1行目、入口は2行目に並べる（幅 320px でも収まる）
- 出している時間を、5秒から **7秒**にする。触っている間は消えない
- 「シェア」は、連続記録が伸びたときに限らず、いつでも出す

### 手ごたえ
- **押した瞬間**：端末を軽く震わせる
  - Android：ブラウザの振動の機能を使う
  - iPhone：ブラウザから震わせる手段がない。画面の外に置いたスイッチを切り替えて、OS の手ごたえを借りる。対応していない端末では、何も起きない
- **サーバーに記録できたとき**：タイルに一瞬 ✓ を出す
- 動きを減らす設定（prefers-reduced-motion）の端末では、✓ の動きは出さない

## 理由
- 新しい画面や部品を増やさずに、詳細とシェアへの道を「必ず目に入る場所」に置ける
- ✓ を「記録できたとき」に出すのは、押した瞬間の反応（震え・動き）と、保存できた合図を分けるため。通信に失敗したときは ✓ が出ず、「記録できませんでした」が出る

## 影響・トレードオフ
- 知らせが2行になり、画面の下を少し広く隠す
- 入口が4つあるので、7秒では選びきれない人がいるかもしれない。取り消しは、10分以内なら長押しシートからもできる（決定 054）
- iPhone の手ごたえは、OS やブラウザの版によって、効かないことがある。実機で確かめる必要がある
- 詳細への道は、これで1つ増えた。「日数の部分を押すと詳細が開く」案（#33）は、押し間違いが増えるおそれがあるので、入れていない
