## 4. 次にやること（順番に）
### 4-1. デプロイの初回設定（Yuki さんのアカウントで操作が必要）
手順は `deploy/README.md`。Claude は手順を案内し、エラーが出たら原因を調べる役になる。
1. Neon：無料アカウントを作る（リージョンは AWS Singapore）。**Pooled** の接続文字列を控える
2. Google Cloud：プロジェクトを作る、請求先を紐づける、予算アラートを設定する、プロジェクト番号を控える
3. OAuth クライアントを作る
   - リダイレクト URI：`https://yattalog-<プロジェクト番号>.asia-southeast1.run.app/accounts/google/login/callback/`
   - 同意画面は「テスト中」にし、テストユーザーに自分を追加する
4. Cloud Shell で `bash deploy/gcp-setup.sh <PROJECT_ID>` を流す。何度流しても大丈夫
5. GitHub の Settings → Secrets and variables → Actions → **Variables** に、スクリプトが最後に出した値と `GOOGLE_CLIENT_ID` を登録する
   - 登録したら Actions の「Deploy」を手動で実行する

注意：`gcp-setup.sh` と `deploy.yml` は、実際の Google Cloud ではまだ一度も動かしていない（CI では構文と Docker ビルドしか確かめていない）。
初回は IAM の権限不足や API の有効化漏れでつまずく可能性がある。エラーの全文を見て直すこと。

## 6. 知っておくと役立つこと（ハマったところ）
- **PostgreSQL の照合**：en_US の照合では "Zz" と "a0" の順が逆になり、並び順が壊れた。`SortKeyField` で "C" 照合を指定して解決した。外さないこと
- **Python 3.14**：`ruff format` が `except (A, B):` を `except A, B:` に書き換える。3.14 では正しい構文なので戻さなくてよい
- **htmx の `HX-Trigger`**：日本語をそのまま入れると MIME エンコードされる。`json.dumps`（ASCII エスケープ）を使う
- **CSP**：インラインスクリプトは禁止。JS は `static/js/app.js` に書く
- **E2E**：`DJANGO_ALLOW_ASYNC_UNSAFE=true` が必要（`e2e/conftest.py` で設定済み）。ログインは `Client.force_login` で作ったセッションの Cookie をブラウザに渡している
  - allauth の認証バックエンドを使うので、自前で作ったセッションは通らなかった
- **テストの時計**：`conftest.py` で 2026-10-10 03:00 UTC（日本時間 12:00）に固定している。日付の境界のテストはこれを前提にしている
