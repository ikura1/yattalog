## 1. これは何か
- **Yattalog（やったログ）**：「前にやったのいつだっけ？」に答えるアプリ。やったら1タップで記録し、前回からの日数がひと目でわかる
- 元は Yuki さんが Django で作っていた **TimeTask**（`ikura1/timetask`）。データの移行や互換性は不要で、一から作り直した（決定 001）
- 参考は習慣アプリの **Streaks**。アイコンのグリッド、タップで記録、連続記録バッジ
- 一般公開する前提。まずは自分だけで使う α、次に先着20人の β（決定 038）、その後に一般公開（決定 030）

## 6. 知っておくと役立つこと（ハマったところ）
- **PostgreSQL の照合**：en_US の照合では "Zz" と "a0" の順が逆になり、並び順が壊れた。`SortKeyField` で "C" 照合を指定して解決した。外さないこと
- **Python 3.14**：`ruff format` が `except (A, B):` を `except A, B:` に書き換える。3.14 では正しい構文なので戻さなくてよい
- **htmx の `HX-Trigger`**：日本語をそのまま入れると MIME エンコードされる。`json.dumps`（ASCII エスケープ）を使う
- **CSP**：インラインスクリプトは禁止。JS は `static/js/app.js` に書く
- **E2E**：`DJANGO_ALLOW_ASYNC_UNSAFE=true` が必要（`e2e/conftest.py` で設定済み）。ログインは `Client.force_login` で作ったセッションの Cookie をブラウザに渡している
  - allauth の認証バックエンドを使うので、自前で作ったセッションは通らなかった
- **テストの時計**：`conftest.py` で 2026-10-10 03:00 UTC（日本時間 12:00）に固定している。日付の境界のテストはこれを前提にしている
- **Google ログイン**：`ACCOUNT_USER_MODEL_USERNAME_FIELD = None` を外すと、ログインの完了時に 500 になる。E2E はログインの流れを通らないので、`test_google_login.py` で守っている
- **秘密の値の貼り付け**：`read -rs` は画面に何も出ないので、二重に貼りやすい（初回設定で2回起きた）。登録したら、長さと形だけを確かめる
  - 確かめるときは、値はもちろん、分解した一部（URL のパラメータ名など）も表示しない。壊れた値では、思わぬところにパスワードが入っている
- **Cloud Run の接続元**：`X-Forwarded-For` の末尾が接続元。先頭は送る側が書ける（本番で確認済み）
- **デプロイの「cancelled」**：続けてマージすると、待っていたデプロイが新しいものに置き換わる。失敗ではない
- **E2E で DB を読むタイミング**：サーバーが書き終わったことを、画面（成功のトーストなど）で確かめてから読む。楽観的更新の表示（「さっき」）を合図にすると、書き込みの途中にぶつかって落ちる（#52 の原因だった。直した）
- **Claude の権限**：`gh pr merge` と Secret Manager への書き込みは止められる。GitHub の設定変更（ブランチ保護など）と Issue の操作はできる
