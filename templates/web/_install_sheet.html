ホーム画面に追加

ホーム画面に置くと、アプリのように1タップで開けます。

{% if platform == "ios" or not platform %}
{% if not platform %}

iPhone・iPad（Safari）

{% endif %}
  1. 画面の下（または上）にある共有ボタン を押す
  2. 出てきたメニューを下へ送り、「ホーム画面に追加」を選ぶ
  3. 右上の「追加」を押す
{% endif %} {% if platform == "ios-other" %}

iPhone・iPad では、Safari で開き直すと、ホーム画面に追加できます。

  1. このページの URL をコピーする
  2. Safari を開いて、URL を貼り付ける
  3. Safari のメニューから、もう一度この案内を開く
{% endif %} {% if platform == "android" or not platform %}
{% if not platform %}

Android（Chrome）

{% endif %}
  1. ブラウザ右上のメニュー（︙）を押す
  2. 「ホーム画面に追加」または「アプリをインストール」を選ぶ
  3. 確認の画面で「インストール」を押す
{% endif %} {% if not platform %}

パソコン（Chrome・Edge）

  1. アドレスバーの右端にあるインストールのボタンを押す
  2. 確認の画面で「インストール」を押す
