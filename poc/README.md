# PoC

仕様を実際に触って確かめるための使い捨てプロトタイプ。本実装（Django）とは別物。

- `index.html`：単一ファイルの HTML/JS。データは `localStorage` に保存する（サーバーなし）
- 公開版：Claude の Artifact として公開している（オーナーのみ閲覧可）

## 回し方

1. SPEC.md のステップを決める
2. PoC に反映し、スマホで触る
3. 気付いたことは Issue に書く（ラベル `poc-feedback`）
4. 仕様の変更が決まったら、決定記録を追加して SPEC.md を更新する
5. PoC の先頭にあるバージョン表記（`PoC v0.x`）を上げる
